# Godot 4.7.2 engine

Official Godot **4.7.2-stable** builds are attached to this repository's
[Releases](../../releases) page:

| Platform | File |
|----------|------|
| Linux x86_64 | `Godot_v4.7.2-stable_linux.x86_64.zip` |
| Windows x86_64 | `Godot_v4.7.2-stable_win64.exe.zip` |

Download, unzip, and run the executable — Godot is self-contained and needs no
installation.

## Or fetch it with a script

```bash
bash download-godot.sh            # Linux / macOS
./download-godot.ps1              # Windows PowerShell
```

Both scripts download the same official files from
`github.com/godotengine/godot-builds` into this folder. The downloaded binaries are
git-ignored.

## Other platforms

macOS (universal, ~163 MB), Linux ARM, and .NET/C# builds are available at the
official download page: <https://godotengine.org/download/archive/4.7.2-stable/>
